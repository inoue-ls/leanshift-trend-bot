# バズるタイトル分析・プロンプト設計書 (viral_title_design)

本書は、システム拡張の機能4「どんな記事が読まれるかの調査」に基づき、海外テックニュースが日本のテックコミュニティ（X、Zenn、Qiita、はてなブックマークなど）で爆発的にシェアされるための「バズるタイトルの法則」の定義、Gemini 向けプロンプト指示文のテンプレート、および既存の `x_post_draft` 生成やレポート保存機能への統合設計をまとめたドキュメントです。

---

## 1. バズるタイトルの法則（海外テックトレンドの傾向から5パターン）

日本のデベロッパーやビジネスパーソンは、単なる情報の直訳よりも「自分にとってのベネフィット」や「インパクトの強さ」が即座に理解できるタイトルに反応します。特に反応率（バズ度）が高い5つのパターンを列挙します。

### パターン①：定量的成果・圧倒的数値（数字の法則）
*   **特徴**: ベンチマーク速度、GitHubスター数、削減コストなどの具体的な「数字」をタイトルに含め、技術の凄さを直感的に伝える。
*   **海外記事元題例**: "Ruff passes 20k stars on GitHub"
*   **改善案（日本語）**: 「**GitHubで2万スター突破！Rust製で超高速動作するPythonツール『Ruff』が凄すぎる**」

### パターン②：既存常識の破壊・対比（対比の法則）
*   **特徴**: これまでの常識や標準とされてきたもの（Webpack、SPA、ローカル環境など）を否定し、新パラダイムへの移行を促すことで強い興味を惹く。
*   **海外記事元題例**: "Why we migrated from Webpack to Vite"
*   **改善案（日本語）**: 「**まだWebpackで消耗してる？私たちがViteへの移行で開発速度を3倍にした理由**」

### パターン③：簡易性・時短・初心者訴求（スピードの法則）
*   **特徴**: 「ノーコード」「〇分で完成」「テンプレートあり」など、学習コストや実装コストが極めて低いことを約束して心理的障壁を下げる。
*   **海外記事元題例**: "Retool AI launches for automated internal tools"
*   **改善案（日本語）**: 「**API開発は一切不要？Retool AIを使って10分で社内サポートAIを作ってみた**」

### パターン④：巨大テック・権威への便乗（権威の法則）
*   **特徴**: OpenAI、Google、Vercel、Appleなどの誰もが知る巨大ブランドや、数千億円規模の資金調達ニュースを利用し、市場のトレンドであることを印象づける。
*   **海外記事元題例**: "Mistral AI raises $600M in Series B"
*   **改善案（日本語）**: 「**OpenAIの最強のライバル？フランス発『Mistral AI』が約940億円を調達した技術的背景**」

### パターン⑤：理由・仕組みへの疑問喚起（探究心の法則）
*   **特徴**: 「なぜ〇〇なのか？」という問いかけや、「〇〇すべき理由」という形式で、技術的・ビジネス的な知的好奇心を刺激する。
*   **海外記事元題例**: "Stable Audio 3.0 allows full track generation"
*   **改善案（日本語）**: 「**なぜ私たちは音楽生成AIを個人開発に導入すべきなのか？Stable Audio 3.0が示す未来**」

## 2. Gemini プロンプト組み込み用指示テンプレート

Gemini の一撃バッチプロンプトの「出力フォーマット指示」および「スキーマ定義」に追加するプロンプトのブロックです。

### 追加するシステムプロンプト指示（指示文テンプレート）

```markdown
# 記事のバズ度評価と日本語タイトルの改善指示
各記事について、以下の情報を追加で評価・生成してください。

1. **バズ度スコア (viral_score)**:
   - 日本のテックコミュニティ（X、Zenn、はてなブックマーク等）において、拡散（リポストやブックマーク）されやすい話題であるかを 1 から 5 の整数で評価してください。
   - 【5点】: トレンド技術の重大発表、劇的な数値実績（100倍高速化など）
   - 【4点】: 人気フレームワーク（Next.js等）のメジャーアプデ、著名スタートアップの巨額調達
   - 【3点】: 実用的なOSSツールの紹介、ニッチだが有用なAI SaaS
   - 【2点】: 標準的な技術チュートリアルや一般的な解説記事
   - 【1点】: 特定領域すぎるニュース、話題性が極めて限定的

2. **改善日本語タイトル (improved_title)**:
   - 日本のデベロッパーのタイムラインで目を引く、ソーシャルメディア（XやZenn等）向けの見出し（30文字程度）を提案してください。
   - 「数字の法則」「対比の法則」「簡易性の法則」「権威の法則」「探究心の法則」のいずれかを必ず適用し、元の英語タイトルの直訳は絶対に避けてください。
```

### 拡張するJSON出力スキーマ（Pydanticモデル定義用）

```python

    rank: int = Field(...)
    article_id: str = Field(...)
```

## 3. 既存の `x_post_draft` およびレポート生成との統合提案

新しく生成した「バズ度スコア」と「改善タイトル」をシステムに反映させ、自動アウトプットのクオリティを底上げするための3つの連携プランです。

### 提案①：X投稿文（x_post_draft）のフックに「改善タイトル」を完全同期する
現在、Xの投稿下書きは「`[絵文字1個＋キャッチーなフック]`」で始まっていますが、ここに Gemini が生成した `improved_title` をそのまま流し込む仕様に変更します。これにより、投稿の「リード文」のクリック率が最大化します。

*   **X投稿下書き生成ルールへの反映指示例**:
    > 「X投稿下書きの1行目は、必ず別項目で生成した `improved_title` の前にふさわしい絵文字を1個付けたものにしてください」

```text
🚀 GitHubで2万スター突破！Rust製で超高速動作するPythonツール『Ruff』が凄すぎる
圧倒的な処理速度を誇るPythonリンターRuffの人気が急上昇中。CI/CDの実行速度を劇的に改善し、開発パイプラインの標準となりつつあります。
https://github.com/astral-sh/ruff
```

### 提案②：Markdownレポート（outputs/）のヘッダーおよびバッジ表示への適用
自動出力される Markdown レポート（`outputs/YYYY-MM-DD_trends.md`）の各見出しを、無機質な英語タイトルから「日本語の改善タイトル」に変更し、バズ度スコアをスター（★）バッジで表記します。

*   **Markdown出力の変更イメージ**:

```markdown
## 🏆 第1位: [Hacker News] GitHubで2万スター突破！Rust製で超高速動作するPythonツール『Ruff』が凄すぎる
- **元記事**: Ruff: The Fast Python Linter Written in Rust Passes 20k Stars
- **元URL**: https://github.com/astral-sh/ruff
- **🔥 バズ度期待値**: ⭐⭐⭐⭐⭐ (5/5)
- **マッチング評価**: 開発環境の改善に寄与するOSSであり、非常に高い拡散が予想されるため1位としました。

### 💡 一言要約
Python開発における静的解析を劇的に高速化するRust製リンター「Ruff」の普及。
...
```

### 提案③：順位付け（Ranking）ロジックへのスコア組み込み
現在設計されている順位付け（ランキング）アルゴリズム「関心50%・ビジネス価値30%・新規性20%」の中に、「バズ度スコア」を新規性/ビジネス価値のサブ指標、あるいは独立した評価軸として算入させます。

*   **調整案A**: 新規性（20%）の中にバズ度を含め、ソーシャル上の広まりやすさ＝トレンド性とみなす。
*   **調整案B**: 加重平均を「関心 45%・ビジネス価値 25%・バズ度 20%・新規性 10%」のように微調整し、日本のSNSで跳ねる可能性が高い記事をアルゴリズム的に優先して順位を押し上げる。
